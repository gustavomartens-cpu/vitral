# Iniciar com o visual do Vitral: plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** O Menu Iniciar passa a usar o vidro, a cor, a borda e os cantos da doca do perfil, por um componente C++
carregado dentro do Iniciar, com reserva por botão quando ele não conecta.

**Architecture:** Regras puras no Core (`Vitral.Core/Iniciar`: perfil, estado, valores, arquivo de cores, decisões);
o editor na Ui; o `ServicoIniciar` no App instala a DLL, grava o arquivo de cores e conecta pela rota externa; a DLL
(`src/Vitral.Iniciar`, C++/WinRT com o clang do G:) pinta o `AcrylicBorder` e reaplica quando o arquivo muda.

**Tech Stack:** .NET 10 WPF, xUnit, C++23/WinRT (llvm-mingw, cppwinrt), XAML Diagnostics (`InitializeXamlDiagnosticsEx`).

**Spec:** `docs/superpowers/specs/2026-11-01-iniciar-design.md` (prova: `docs/superpowers/specs/2026-11-01-fase2-prova-iniciar.md`)

## Global Constraints

- Testes: `powershell.exe -NoProfile -Command '. tools/env.ps1; dotnet test --nologo -v q'`; feche o Vitral antes
  (`Get-Process Vitral | Stop-Process -Force`).
- Código, nomes e comentários em português, no estilo dos vizinhos; commits terminam com
  `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Esquema do perfil continua **4**; seção nova `iniciar`, enum em texto, lida pelo `EnumTolerante`.
- Permissão do Iniciar: `ALL APPLICATION PACKAGES` = SID `S-1-15-2-1` (leitura na pasta da DLL; escrita nas de cores e log).
- CLSID do componente novo (não reusar o da fase 0): `{9C3E7A14-2B6D-4F1E-8A53-61D0C47B2E95}`.
- Mutex por processo: `Local\VitralIniciar-<pid>`. Dados de inicialização: `hostpid=<n>;cores=<caminho>`.
- Raio: Retos 0, Suaves 4, Redondos 8. Conexão: varredura `VisualDiagConnection1..10000`, repetida a cada 2 s até 90 s.
  Vigia do PID do Iniciar: a cada 5 s.
- Textos da janela (exatos): "Iniciar com o visual do Vitral"; "Iniciar com o visual do Windows: {motivo}"; botão
  "Usar a cor de destaque do Windows no Iniciar"; motivos: "o Windhawk está usando o Iniciar", "o Iniciar não aceitou o
  componente", "o Windows mudou o Iniciar", "o componente não foi encontrado".
- A DLL nunca derruba o Iniciar: todo callback em `try/catch(...)` com log.

## Review Focus

1. O Windows reinicia o Iniciar (atualização, Explorer reiniciado) com o Vitral aberto → reconecta sozinho (Task 2, `PID novo conecta de novo`).
2. Atualização do Vitral com o Iniciar segurando a DLL da versão antiga → a pasta antiga fica até ser liberada, sem erro (Task 2, `Pastas antigas`).
3. Windhawk aberto → não conecta e mostra o motivo, sem tentar a cada 5 s em loop barulhento no log (Task 2).
4. Transparência do Windows desligada → doca sólida → Iniciar sólido opaco (Task 2, `Sem transparencia vira solido`).
5. Perfil com Iniciar "Não mexer" depois de outro com "Combinar" → mantém o Vitral (Task 1, `Nao_mexer_mantem`).
