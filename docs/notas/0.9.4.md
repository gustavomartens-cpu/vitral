## Abrir a conversa certa no Claude

"abrir no Claude ›" na ficha de resposta, "Abrir no Claude" na lista de Pendências e o clique no aviso do Claude no
notch passam a abrir **exatamente a conversa** que gerou o aviso, em vez de só trazer o app para a frente.

Vale para as sessões do app do Claude que terminarem já com esta versão. Sessões do Claude Code no terminal continuam
só trazendo o app.
