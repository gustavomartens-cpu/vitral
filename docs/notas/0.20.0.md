## Arrastar arquivo para a doca

- **Segurar o arquivo sobre um ícone da doca** traz o app para cima, como na barra de tarefas do Windows. Com uma
  janela aberta, ela sobe; com várias, aparecem as miniaturas, e segurar o arquivo sobre uma delas sobe aquela
  janela. Ainda segurando o arquivo, é só levá-lo para dentro da janela e soltar (num site, num e-mail, onde quiser).
  Com o app fixado e fechado, ele abre.
- **Soltar o arquivo no ícone** abre o arquivo com o app: uma imagem ou um vídeo solto no Chrome abre numa aba.
  Apps da loja (como o Claude) não abrem arquivos soltos no ícone; o cursor mostra que ali não dá para soltar, mas
  segurar para trazer a janela funciona.
