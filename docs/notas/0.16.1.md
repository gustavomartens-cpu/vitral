## Acertos do painel de controles

- **Brilho:**
  - cada monitor fica preso à sua saída de vídeo (desligar um não faz o controle mexer no outro);
  - o último valor arrastado é gravado mesmo fechando o painel na hora;
  - o painel acompanha monitor ligado ou desligado com ele aberto;
  - o deslizante mostra o brilho mudado pelas teclas Fn ou pelo Win+A.
- **Bluetooth:**
  - aparelhos com o mesmo nome aparecem separados;
  - fones ligados só pelo Bluetooth de baixo consumo continuam como fone;
  - o controle 8BitDo ganha o ícone de controle.
- **Microfone:** o mudo vale também para o microfone que o Teams e o Zoom usam, e a lista de microfones some quando o
  Windows não deixa trocar o padrão.
- Não perturbe e luz noturna não seguram mais a barra enquanto o Windows responde.
